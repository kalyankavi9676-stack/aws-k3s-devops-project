# Static Website Hosting Using AWS S3 and CloudFront

## Project Overview

This project demonstrates how to host a static website using Amazon S3 and distribute website content globally using Amazon CloudFront.

AWS services such as S3, CloudFront, CloudWatch, and SNS are used to understand website hosting, content delivery, monitoring, and notifications.

## Objective

To deploy a static website using Amazon S3 and CloudFront and understand how AWS services help provide scalable and reliable website hosting.

## AWS Services Used

- **Amazon S3:** Used to store static website files such as HTML, CSS, and JavaScript.
- **Amazon CloudFront:** Used to distribute website content through a global content delivery network (CDN).
- **Amazon CloudWatch:** Used to monitor CloudFront metrics and configure alarms.
- **Amazon SNS:** Used to send notifications when configured alarm conditions are triggered.

## Project Implementation

1. Created an Amazon S3 bucket.
2. Uploaded static website files to the S3 bucket.
3. Enabled static website hosting.
4. Created an Amazon CloudFront distribution.
5. Connected CloudFront with the S3 website origin.
6. Configured CloudWatch monitoring and a CloudFront 4xx alarm.
7. Used Amazon SNS for notification configuration.

## Key Learnings

- Understanding Amazon S3 bucket creation and file management.
- Learning static website hosting.
- Understanding CloudFront distributions and content delivery.
- Monitoring AWS resources using CloudWatch.
- Understanding alarm notifications using SNS.

## Project Outcome

Successfully completed a practical AWS project to understand static website hosting, content delivery, monitoring, and notification services.
